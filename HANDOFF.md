## Project rules (do not break)

- **Ionic Framework + Angular only** (course requirement). The app is in `app/` (Ionic 9, Angular 22, standalone components, signals, zoneless).
- **Backend:** Node.js + Express in `server/`, database is **Neon PostgreSQL**. The app never talks to the database directly; it calls the API.
- **Secrets:** `server/.env` holds the Neon connection string. **Never commit it.** Teammates copy `server/.env.example` and get the string privately from the leader.
- **Design:** cocoa brown (`#4a3024` / `#523628`) on bakery pinks (`#fff5f7`, `#fce7f3`, accent `#f472b6`). Fonts: **Fraunces** (headings) + **Plus Jakarta Sans** (body).
- **Flat UI: no drop shadows** anywhere. Separate surfaces with color and thin borders.
- **No emojis** in the UI, docs or logs. Use SVG icons only: Ionicons, or the custom `cf-*` icons in `app/src/app/brand-icons.ts`. Every icon must be registered in `app/src/app/icons.ts`.
- **Commits:** commit under your own GitHub account. No AI co-author or "generated by" lines in commits or files.
- Keep code style consistent with the existing files (short doc comment at the top of each file, signals for state).

## How to run

```bash
npm run setup     # first time: installs root, server and app
npm run dev       # starts the API (port 3000) and the app (port 4200)
```

The API creates and updates the Neon tables automatically on start (`server/src/db.js`), including one-time migrations recorded in the `app_meta` table. More detail is in `README.md`.
